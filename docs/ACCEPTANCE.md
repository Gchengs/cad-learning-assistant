# 验收清单

面板与交互只能人工看，这份清单按「一条一句话、能勾」写。带 ⚠ 的是本轮改动重点。

## 0. 版本

- [ ] 关掉所有 AutoCAD 窗口，重新 `build-vs.bat`（DLL 被占用会报 `MSB3021`）
- [ ] `bin\Debug\` 下 DLL、`questions.json`、`images\`（22 张）都在
- [ ] 启动横幅显示「第十二版·图表面板，共 26 题」

## 1. 面板布局

- [ ] ⚠ 选 1-A：图区高约 190–200px，**不是空白、也没被压成一条缝**
- [ ] ⚠ 走到「15. 做完后自查」这种长文字步骤：图区高度不变，文字框里出现滚动条
- [ ] 拖动面板边缘改宽度/高度，图按比例缩放，不变形、不溢出
- [ ] 四块从上到下顺序正确：选题目 / 当前步骤 / 图 / 这步怎么做

## 2. 三行指令

- [ ] 形如 `① 点　…` / `② 敲　…` / `③ 记　…`，命令里的回车是 `↵`
- [ ] `③ 记` 只有一句（不超过 42 字，超出以「…」结尾）
- [ ] 没有「面板：」「命令：」「要点：」这类旧前缀
- [ ] 面板路径里没有「（Ribbon 无独立按钮）」这类括注
- [ ] 点【我不会，帮我继续】：命令行出现「完整要点：…」（被截断的原文）

## 3. 结果图

- [ ] ⚠ 切 5-A / 6-A / 8-B，图跟着换成端盖 / 平板件 / 法兰盘
- [ ] ⚠ 点图弹出大图，尺寸约为屏幕可用区域的 88%，标题是「题号 + 标题」
- [ ] 大图里点一下或按 `Esc` 能关；关闭后 CAD 仍可操作
- [ ] 把 `images\5-A.png` 改名后重开 5-A：显示「本题没有结果示意图」，其余功能正常
- [ ] 图片角标区分「按题面尺寸画」与「配套 DWG 渲染」

## 4. 按钮语义

- [ ] 题库题（1-A 等）点【我做好了，下一步】：只翻页，命令行说明「未自动验收」
- [ ] 走到最后一步：按钮变灰并显示【已到最后一步】
- [ ] CAD 命令执行中点按钮：不重复发命令，只提示当前命令未结束
- [ ] 3.1 点【我不会，帮我继续】能建练习副本并推进，最后保存通过后变【检查整题】

## 5. 指针与提示

- [ ] 有经典菜单路径的步骤会画箭头指向菜单项
- [ ] 指不到时命令行说明原因（菜单栏没开 / 路径未核实 / 窗口不在前台），不是静默无反应
- [ ] 3-C 第 3 步只指到「对象选择过滤器」，不会去找不存在的「应用」菜单项

## 6. 稳定性

- [ ] 连续切 26 道题、每道题逐步翻到底，不崩、不报未处理异常
- [ ] 高亮/箭头后切图、关图、隐藏面板、退出 CAD，无残留
- [ ] 重启 CAD 后不假装恢复上次练习的绑定或完成状态

## 反馈模板

> 题号 / 步骤 / 点了哪个按钮 / 命令行最后 5–10 行 / 截图

旧版本的通过记录不作为本轮证据。
